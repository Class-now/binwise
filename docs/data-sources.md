# Data sources

BinWise answers come only from the rules dataset in `data/wards/`. The AI identifies items and translates text; it never decides a category. This file records where every rule came from.

All pages were read on 2026-11-10 from the wards' official sites (city.shibuya.tokyo.jp, city.shinjuku.lg.jp, city.setagaya.lg.jp) and the bulky-waste booking sites those pages link to. Raw copies were kept outside the repository; only the extracted facts are committed.

## How the dataset is built

| File | What it holds |
|---|---|
| `data/src/items.mjs` | 181 household items shared by all wards: names and aliases (ja, en, zh, ko, vi, ne), separable parts, generic tips, common mistakes |
| `data/src/categories.mjs` | Colour, icon, English name and "what happens after collection" for each category id |
| `data/research/<ward>.json` | Per ward: official categories, how to put each out, collection frequency, and for each item its category, preparation steps, notes, source URL and the quoted rule |
| `data/src/en/<ward>.json` | English for every Japanese rule string |
| `data/wards/<ward>.json` | Generated by `npm run data` (`scripts/build-data.mjs`), then checked by `scripts/validate-data.mjs` (also run in `test/data.test.ts`) |
| `data/wards/shibuya-schedule.json` | Shibuya's collection days by 町丁目, from the ward's HTML table |

Every item has `source` (the official page that lists it or states the rule) and `derived`:

- `derived: false` — the ward lists the item by name (its sorting dictionary, an A–Z list, a category page or the bulky-waste fee list). `ruleQuote` holds the entry.
- `derived: true` — the ward does not name it, so the category follows from a general rule, and `ruleQuote` quotes that rule. Items that no official page covers are not guessed. They are put in a "not listed / ask the waste collection office" category (`unlisted` in Shibuya, `consult` in Setagaya).

## Differences between the wards that the data reflects

- **Plastic.** Shibuya collects packaging and product plastic together as 資源 since July 2022. Shinjuku does the same as 資源プラスチック since April 2024. Setagaya does not collect plastic separately: plastics are 可燃ごみ. The ward's 11th sorting plan aims to start separate collection during FY2030 (令和12年度). Setagaya has no `plastic` category.
- **Batteries and spray cans.** Shinjuku collects spray cans, gas canisters, dry-cell batteries and (from April 2025) rechargeable batteries on the 資源 day in separate bags. Setagaya puts them in 不燃ごみ in separate labelled bags; rechargeable batteries have done so since October 2025. Shibuya collects spray cans as 資源 and dry cells as 不燃ごみ, and sends rechargeable and button batteries to shop collection boxes.
- **Fluorescent tubes** are a 資源 stream in Shibuya. In Shinjuku and Setagaya they are 不燃ごみ.
- **Shinjuku's non-burnable stream** is officially named 金属・陶器・ガラスごみ. It uses the id `nonburnable`, and its Japanese name is shown as published.

## Terms of use and how we comply

All three wards hold the copyright to their web content and restrict reproduction (quoted per ward below). BinWise therefore:

- uses the rules as **facts** (which bin an item goes in, which day, what size limit). Facts are not protected by copyright. Preparation steps and notes are short restatements, not copies of the ward's pages.
- keeps verbatim text only in `ruleQuote`, as a short **quotation with its source URL** (引用, Copyright Act Art. 32) so that every answer can show where it came from.
- **links to the official page** on every answer card, and to the ward's sorting search when an item is not found.
- does not copy images, illustrations, PDFs or layouts. Shinjuku asks sites not to link to its PDFs directly, so item sources point to the HTML pages that host them.
- states in the app and README that this is an unofficial guide and that the ward's own pages take precedence.

Rules change. `scripts/check-sources.mjs` re-checks these URLs for content changes against the baseline in `data/source-hashes.json` (see `docs/impact.md`).
